## Установка

По кабелю:

```bash
adb install -r /home/gadel/projects/raschet-beton-android/release/Beton-1.0.apk
```

Или скопировать `Beton-1.0.apk` на телефон и открыть файл. Android может попросить
разрешить установку из этого источника.

## Пересборка после изменений в веб-приложении

```bash
cd /home/gadel/projects/raschet-beton-android
npm run build
npx cap sync android
cd android
ANDROID_HOME=/home/gadel/Android/Sdk \
JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64 \
./gradlew assembleRelease
```

Готовый APK появится в `android/app/build/outputs/apk/release/app-release.apk`.

## Ключ подписи

- `beton-release.keystore` — ключ подписи;
- `keystore.properties` — пароли и алиас.

**Сохраните оба файла.** Обновление приложения поверх установленного должно быть подписано
тем же ключом, иначе Android откажется устанавливать новую версию.

## Исходный проект

Основной исходник (PWA):

`/home/gadel/projects/raschet-beton`

Android-обёртка и все настройки сборки лежат в отдельной копии, веб-часть
синхронизируется из основного проекта перед сборкой:

`/home/gadel/projects/raschet-beton-android`

Текущий APK собран из основного проекта 14.11.2026 и включает: именованные расчёты и папки
на главном экране, компактную карточку объёма во всю ширину, круглую кнопку сворачивания
нижней панели в одной строке с вкладками, перетаскивание и пинч, начатые с подписи размера,
уменьшение и скрытие подписей при отдалении, широкое поле ширины участка, возврат «К контуру»
из выбранного ребра или вершины, переход к полю отступа тапом по его числу на холсте
(с прокруткой и подсветкой), красные кнопки «Очистить холст», скрытие клавиатуры после ввода
длины, отступа и ширины, а также переключатель «Зуб отмостки» с полями ширины и глубины
(по умолчанию 150 × 150 мм). Зуб идёт только по внешнему контуру ленты, а его объём
прибавляется к общему объёму. Долгое нажатие на глубину отрезка не сбрасывается к общей.

Зелёная сторона теперь фиксирует именно длину: противолежащая зелёная сторона не
подстраивается под новое значение. Если свободной параллельной стороны в кольце нет,
ввод отклоняется стандартным диалогом с просьбой открепить одну из параллельных зелёных
сторон. Закреплённые перпендикулярные стороны удерживают и положение: одна закреплённая
стоит на месте, две смещаются равномерно. Учитываются обе стороны полосы, а число отрезков
на противолежащих сторонах может различаться. Из блока с кнопкой «Очистить холст» у ленты и
плиты убраны счётчики точек, отрезков и закреплений. Расчёты получают имя («Плита», «Плита 2»,
«Лента»…), переименовываются в шапке редактора или через меню «⋯», переносятся в именованные
папки и между ними; удаление папки удаляет и все расчёты внутри после отдельного
подтверждения. Кнопка «+ папка» увеличена до 104 × 44 px — по ней удобно попадать пальцем.
